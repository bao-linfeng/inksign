# 墨签 InkSign 品牌图标

图形由钢笔笔尖与签名收笔组成，使用墨蓝 `#1E3A5F` 和纸白 `#FAF9F6`。浅色、深色版本指使用背景，图标外侧圆角区域透明。SVG 不依赖字体、外部资源或第三方服务。

| 文件（相对 `apps/web/public/`） | 用途 |
| --- | --- |
| `brand/logo-light.svg`、`brand/logo-light.png` | 浅色背景使用，墨蓝底、纸白笔尖；PNG 为 512 × 512 |
| `brand/logo-dark.svg`、`brand/logo-dark.png` | 深色背景使用，纸白底、墨蓝笔尖；PNG 为 512 × 512 |
| `favicon.svg` | 按浏览器 `prefers-color-scheme` 自动切换颜色 |
| `favicon.ico` | 浅色版多尺寸 ICO，兼容不支持 SVG favicon 的浏览器 |
| `brand/favicon-dark.ico` | 深色版多尺寸 ICO，供手动使用 |
| `apple-touch-icon.png` | 180 × 180，墨蓝不透明底色，供 Apple 主屏幕使用 |

两个 ICO 均包含 16、24、32、48、64、128、256 像素图像。ICO 为固定配色，自动配色由 SVG favicon 提供。

`AppLogo.vue` 保留“墨签 / InkSign”文字，按 `.dark` 类选择图标。此改动提供深色品牌素材，不添加整站深色主题。

打开 [预览页面](brand-preview.html) 可查看两种配色及小尺寸效果。
